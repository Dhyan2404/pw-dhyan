# PW DHYAN

Dedicated Study Portal Android Application built by **Dhyan**.

### Features
- Master Security Access with Cloud Sync (Firebase Firestore).
- 1-Key 1-Device lock system.
- Custom WebEngine with vertical video view lock.
- Automated GitHub Actions APK build pipeline.

### Build via GitHub Actions
Every push to this repository automatically triggers the build workflow and outputs an APK artifact (`PW-DHYAN-App-Debug`) under the **Actions** tab.
